# 📊 Telegram Web Analysis Tool

**Telegram Analysis** — это мощный инструмент для автоматизированного сбора, парсинга и экспорта данных из веб-версии Telegram. Полезен для сохранения архивов чатов, анализа контактов и исследования статистики общения.

---

## 🚀 Особенности
- **🤖 Автоматизация браузера**: Работает на базе Selenium WebDriver, эмулируя действия реального пользователя.
- **📩 Экспорт чатов**: Позволяет скачивать и сохранять текстовые логи переписок из диалогов.
- **👥 Анализ контактов**: Сбор метаданных контактов и информации из групп.
- **📜 Скроллинг**: Автоматическая прокрутка истории для подгрузки старых сообщений.
- **🔐 Без ключей**: Не требует Telegram API ключей — использует сессию через веб-браузер.

## 🛠 Технологии
- **Python 3.x**
- **Selenium** — автоматизация веб-браузера.

## 📥 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/PrivetVirus/telegram_analysis.git
   ```
2. Установите необходимые библиотеки:
   ```bash
   pip install selenium
   ```
3. Скачайте [WebDriver](https://chromedriver.chromium.org/) для вашего браузера (например, Chrome) и добавьте его в `PATH`.
4. Запустите скрипт:
   ```bash
   python selenium_export.py
   ```
5. В открывшемся окне браузера отсканируйте QR-код для входа в свой аккаунт Telegram.

## ⚠️ Важное замечание
Этот скрипт разработан **исключительно для образовательных целей и личного использования** для анализа собственных чатов. Пожалуйста, уважайте конфиденциальность и не используйте его для спама или сбора данных третьих лиц без их согласия.
