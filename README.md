# Telegram Analysis 📊

Инструмент для экспорта и анализа данных из веб-версии Telegram с использованием **Selenium WebDriver**. 

**Возможности:**
- `selenium_export.py` — автоматизированный сборщик переписок и информации о контактах.
- Позволяет выгружать данные для последующего анализа (например, построения графов связей или NLP).
